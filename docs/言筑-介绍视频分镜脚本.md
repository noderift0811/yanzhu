# 言筑 YanZhu · 介绍视频分镜与脚本

> 第九届传智杯 · AI WEB 网页开发挑战赛 · 队名「未命名者」
> 产品经理视角创作稿 ｜ 主版本 **约 2 分 15 秒（135 秒）** ｜ 附 90 秒 / 60 秒裁剪方案
> 演示账号：`demo` / `yanzhu2026`；成片规格 1920×1080 / H.264 / 硬字幕

## 一、创作策略（为什么这样剪）

### 1.1 一句话定位

> **AI 交付的不是一段文字，而是界面本身；说完几个词，你得到的是一个天天回来的网站。**

这句是全片的"题眼"，必须在 0:20 前说出来，并在结尾原样回扣一次。

### 1.2 评委看完必须记住的三件事

介绍片不是功能清单。2 分钟里评委只会带走三样东西，其余都是佐证：

| # | 记忆点 | 一句话说法 | 凭什么信（画面证据） |
|---|---|---|---|
| 1 | **产物是网站，不是对话框** | "AI 交付的不是一段文字，是整个网站" | 登录后直接落进人格页，没有引导页 |
| 2 | **AI 怎么干活全程可见** | "五步摊开给你看，每步工具调用都推到屏幕上" | 时间线逐条点亮 + 证据卡 + JSON 字段滚动 |
| 3 | **交付之后还在长** | "说加朵花，它就真放一朵花" | AI 装修实时变色放摆件、伙伴日历、追问气泡 |

### 1.3 亮点优先级与取舍

产品经理的判断：**把 60% 的时长给"别人没有的"，40% 给"别人也有但我更稳的"。**

- **重头戏（必须给足镜头）**：言筑退场式落点、五步 Agent 透明化、AI 装修落地元素。这三点是差异化，剪成"可数、可看、可复现"。
- **快切带过（有证据即可）**：双模型分工、场景服务端约束、安全护栏、16 套骨架。这些是评分项，用字幕压屏 + 1–2 秒画面点名，不展开操作。
- **主动不剪**：注册流程、场景选择弹窗、配额数字、技术架构图。评委看得见的事实用提交说明讲，视频里出现就是浪费节奏。

### 1.4 与《90 秒演示分镜》的差异

| 维度 | 90 秒演示分镜（已有） | 本介绍视频（本稿） |
|---|---|---|
| 目标 | 证明**功能能跑**、步骤可复现 | 证明**作品值得记住**、价值成立 |
| 叙事 | 按操作顺序走：登录→调参→新建→五步→人格库→护栏 | 按价值递进走：钩子→痛点→亮相→三个"凭什么"→升华 |
| 开头 | 平缓进入登录页 | 反常识钩子，3 秒内抛问题 |
| 五步段落 | 26 秒逐步展示 | 25 秒，但改成"旁白追问式"——每步回答"它凭什么" |
| 新增亮点 | 无 | AI 装修放花、伙伴日历、追问气泡、自由摆件 |
| 用途 | 提交材料（≤90 秒硬要求时启用裁剪版） | 路演 / 在线展示 / 答辩开场 / 项目介绍页 |

> 两份脚本共用同一套演示账号和界面，可分别录制；若只允许交一条片，用第六节的 90 秒裁剪表。

## 三、口播脚本（连读版，约 500 字 / 118 秒）

> 语速按 4.2 字/秒；每段之间留 0.3–0.5 秒气口，不要抢字。加粗句为重音。

我们都见过 AI 生成网页。但你见过 AI 交付一个"家"吗？

大多数 AI 产品给你一个对话框，聊完就散，下次回来，又是一张白纸。

言筑不是对话框。**你说几个词——温柔、安静、话不多但每句都接得住——它给你搭出一整个网站。**

更特别的是，从这一刻起，言筑自己就退场了。下次登录，你直接落在自己的页面上——这里每一处纸、字、称呼，都是它按那几个词搭的。

想再养一个不一样的自己？新建一个。接下来，它怎么搭的，全程摊开给你看。

第一步检索——只在你的场景语料里找依据，命中的每一条都能点开看原文。第二步规划——定骨架、定语气，也定下哪些话不能说。第三步生成——**它只输出结构化 JSON，一行代码都不写。** 第四步校验，第五步兜底——任何一步失败，都有确定性的退路。

出来的不是模板，是它为我挑的骨架和配色。

站点交付了，它还在长。我说一句"加朵花"，它就真的在页面上放了一朵花——配色和摆件先预览，我点头才保存。右下角的伙伴记着我们聊过的日子；每次回复完，它还替我想好接下来能问什么。

而它克制的一面同样重要：场景由服务端说了算，改参数绕不过去；越界的话，它不说教、不沉默，把求助的方式递给你。

**十六套手写骨架，零代码生成。言筑——你说，它筑。**

## 四、重点镜头的拍法与包装

### 4.1 钩子（0:00–0:08）——决定评委看不看下去

- 前 3 秒不要出现产品 Logo，先抛问题，让观众产生"这是什么意思"的悬念。
- "家"字出来时再切登录页，画面从纸感品牌区缓慢推近，给质感一个下马威。
- 不用旁白念网站名；网站名留给落版。

### 4.2 言筑退场（0:28–0:40）——全片最重要的价值主张

- **必须拍到刷新后仍在本页**。这是"工具→专属网站"范式转移的唯一硬证据，比任何口播都有力。
- 刷新前后画面不要剪断，用同一机位连续录，让观众确认是同一次会话。
- 旁白"言筑自己就退场了"时，画面上不应出现任何言筑品牌元素（聊天页已做去言筑化，页脚落款在沉浸时才出现）——**画面和话要互相证明**。

### 4.3 五步 Agent（0:40–1:22）——差异化核心，占全片 1/3

- 旁白改成**追问式**："它凭什么搭得对？"每一步都在回答一个"凭什么"，而不是报步骤名。
- 语速压慢一档，让五个步骤**可数**。实测五步 11.3 秒，铺满 42 秒镜头需放慢到约 0.45×，或用原速 + 每步关键帧停 1 秒凑时长；**不要把五步剪成一步**。
- JSON 字段滚动段给 1.5× 并轻微推近（scale 1.04），否则 1080p 缩放后字太小。
- 校验段把"边界注入（求助资源写进 system_prompt）"高亮，为后面护栏段埋伏笔。

### 4.4 AI 装修放花（1:35–1:48）——最有记忆点的一刀

- 用真实模型录（当前 `.env` 已接火山方舟，`mock=false`）；Mock 版会带前缀，一眼露馅。
- 录两段素材：①浮窗内结果卡 + 花已在背景页面出现；②关掉浮窗后的页面特写。剪在一起，**证明不是预览特效而是真落库**。
- "加朵花"这句口播要略带惊喜感，这是全片唯一的情绪高点。

### 4.5 收尾（2:08–2:15）——把记忆点钉回去

- 落版只放四行：作品名 / 一句话定位 / 队名院校 / 仓库地址。不要放二维码（缩放后扫不出）。
- 最后一句"你说，它筑"和开头"交付一个家"形成闭环，语速放慢、留 0.5 秒静帧再黑场。

## 五、节奏 / 音乐 / 字幕 / 转场

| 项 | 规范 |
|---|---|
| **节奏曲线** | 钩子慢 → 痛点快 → 亮相定 → 五步慢（可数）→ 生长快 → 克制稳 → 收尾慢。忌全程一个速度。 |
| **BGM** | 0:00–0:18 无音乐；0:18 起轻纸感/钢琴，音量 ≤ −26dB，全程不压口播。评审常在嘈杂环境看片，人声绝对优先。 |
| **音效** | 只用三种：钩子"叮"、证据卡"嗒"、花出现"轻扬"；不要罐头掌声和 whoosh。 |
| **字幕** | 硬编码，≥28px，深墨色 + 1px 纸色描边；每屏 ≤ 14 字；题眼句加粗变大一号。 |
| **转场** | 统一 0.2 秒淡入；仅痛点划除、揭晓白闪两处例外。禁止花哨转场抢走产品画面。 |
| **首尾** | 各留 0.5 秒静帧，避免播放器起播吃掉第一句 / 结尾被截断。 |

## 六、裁剪方案（同一批素材，三种时长）

> 同一批素材剪三版；下表直接给出各段时长，相加即目标时长，便于剪辑核对。五步本体 = 检索规划13 + 生成9 + 校验兜底8 = 30s，过渡造站另计 12s。

| 版本 | 时长 | 各段时长（相加 = 目标） | 删除段落 |
|---|---|---|---|
| **主版本** | 135 秒 | 钩子8 + 痛点10 + 亮相10 + 退场12 + 过渡12 + 五步30 + 揭晓13 + 放花13 + 伙伴追问10 + 克制10 + 收尾7 | 无 |
| **90 秒提交版** | 90 秒 | 钩子5 + 亮相8 + 退场8 + 过渡8 + 五步26 + 揭晓10 + 放花13 + 收尾12（含落版） | 痛点、伙伴追问、克制（三段全删）；其余按表压缩 |
| **60 秒路演版** | 60 秒 | 钩子5 + 亮相8 + 退场7 + 五步快切20 + 放花12 + 收尾8 | 痛点、过渡、揭晓、伙伴追问、克制全删；五步只留检索/生成/兜底三步，字幕补"规划/校验略" |

> 若只需交一条片且规则写死 ≤90 秒，用 90 秒版；主版本留给在线展示页和答辩开场。

## 七、开录前检查清单

| # | 检查项 | 不通过的后果 |
|---|---|---|
| 1 | `backend/.env` 两组 `*_API_KEY` 非空且可用 | 静默降级 MockAdapter，聊天带「（Mock·苏桃）」前缀，放花段会露馅 |
| 2 | 后端 `http://127.0.0.1:8100/docs` → 200；前端 `4180` → 200 | 白录 |
| 3 | demo 账号可登录，主场景 `care`，主页面为「苏桃」 | 退场段证据链断裂 |
| 4 | 人格库有苏桃 / 枕月 / 比特三张卡，苏桃实心星标 | 多站点叙事不成立 |
| 5 | 浏览器 F11 全屏、系统缩放 100%、关通知与书签栏、开专注助手 | 1080p 被缩放糊掉或弹窗入镜 |
| 6 | 正式录前**先空跑一遍**五步生成和放花 | 模型排队会导致镜头时长失控 |
| 7 | 字幕文件与配音稿逐字校对，尤其"言筑"不要写成"演绎"之类谐音 | 硬字幕错了无法后期改 |

> 若 demo 人格被测试脚本归档：重启后端，`app/demo.py` 幂等恢复；仍为空则手工把「苏桃」置 active 并设为主页面。

## 八、风险预案

| 风险 | 触发 | 预案 |
|---|---|---|
| 放花段返回 Mock 或没出花 | 密钥失效 / 关键词未命中 | 换 `.env` 模型到 `deepseek-v4-flash-ga-260731`；或改用确定性兜底路径（"我想加一朵花"命中率高）重录该段 |
| 五步生成排队超 30 秒 | 模型拥塞 | 提前预热；该段接受 2.5× 加速，但必须保持五步可数 |
| 刷新没回到人格页 | 主页面星标被改 | 人格库重新点苏桃星标设主页面，不耗配额 |
| 追问气泡没出现 | 生成建议失败 | 兜底问题仍给 3 条；若真为空，改拍人格设置段替补 |
| 录到一半 401 | 令牌 15 分钟过期 | 开录前重新登录，单段不超过 10 分钟 |
| 危机段画面涉及敏感内容 | 护栏演示 | 只截护栏结果卡（求助资源），不展示输入全文 |
