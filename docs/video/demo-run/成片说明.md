## 复现命令

在 `docs/video/demo-run/` 目录下（需 ffmpeg 8.x，启用 libass）：

```bash
# 1. 原始录屏烧录硬字幕（film.ass 按镜头切点 7/12.6/24/37.5/40/48/51.4s 配时）
ffmpeg -i demo-raw-1080p.mp4 -vf "ass=film.ass" -c:v libx264 -crf 18 -pix_fmt yuv420p -an 主片.mp4

# 2. 生成 3.5s 纸色落版卡（outro.ass 定义四行文字样式）
ffmpeg -f lavfi -i "color=c=0xF4EFE4:s=1920x1080:d=3.5:r=25" -vf "ass=outro.ass" \
  -c:v libx264 -crf 18 -pix_fmt yuv420p outro.mp4

# 3. 拼接
printf "file '主片.mp4'\nfile 'outro.mp4'\n" > concat.txt
ffmpeg -f concat -safe 0 -i concat.txt -c copy 言筑-介绍视频-最终.mp4
```

## 关于配音（诚实说明）

成片**无配音，仅有硬字幕**。原因：本机在线 TTS（edge-tts）因沙箱网络策略无法连接语音服务，Windows 本地 SAPI 又被安全策略拦截。字幕文案完整覆盖分镜脚本的口播稿，信息传达不受影响；评审可静音阅读字幕，或在有 TTS 的环境按 `film.ass` 的逐句时间码补配旁白。

## 与脚本主版的差异

分镜脚本主版设计 135 秒、13 个镜头，含「痛点空白对话框划掉」「骨架画廊扫过」等镜头。本次录屏素材未覆盖这两镜，故成片按**实际录制到的画面**重切为 57 秒，字幕与叙事结构仍遵循脚本（钩子→退场→五步→生长→落版）。若需 135 秒完整版，需补录这两镜后按脚本时间码重剪。
